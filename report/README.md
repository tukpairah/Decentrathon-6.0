# Support Copilot: отчёт команды Undefined

Decentrathon 6.0, кейс 03 Grand Mobile. Сервис `POST /triage` разбирает обращение игрока: язык,
категория, приоритет, спам и дубли, факты, черновик ответа с цитатами правил и решение «нужен ли
человек». Главное требование кейса: не выдумывать правила и не обещать разбан, возврат средств или
наказание другого игрока; платежи, апелляции и взломы всегда идут человеку.

> Финальные прогоны 31.10.2026 на `tickets_valid.jsonl`: все 1000 тикетов в режиме шаблонов (без LLM,
> с золотым набором) и 40 тикетов с LLM-генератором (бесплатный тариф Gemini). Полный прогон 1000
> тикетов с LLM на бесплатном тарифе не помещается в дневную квоту.

## Архитектура

`POST /triage` → нормализация и язык → классификация (категория, приоритет, уверенность) →
факты и спам → поиск правил (BM25 + `multilingual-e5-small`, слияние RRF) → черновик ответа
(`gemini-3.1-flash-lite`, цитаты только из найденных правил) → валидатор цитат и guards → ответ по
контракту. Подробности в разделах выше.

## Итоговые метрики

Критерии и веса взяты из условия кейса. Как считали каждую метрику, описано в
[evaluation.md](evaluation.md).

| Критерий (вес) | Метрика | Значение |
|---|---|---|
| Классификация (25%) | accuracy / macro-F1 категории, золотой набор (n=120) | **46,7%** / 0,315 (было 25,8%; заглушка 26,7%) |
| | accuracy / macro-F1 приоритета, золотой набор | **70,0%** / 0,537 |
| Качество черновиков (30%) | оценка LLM-судьи 1-5: черновик / ответ админа | **2,53** / 2,33 (15 тикетов) |
| | черновик не хуже ответа админа / оценка 4-5 | 66,7% / 26,7% |
| Нет галлюцинаций (20%) | выдуманных цитат | **0** (во всех прогонах) |
| | тикетов с цитатами (прогон с LLM, 40) | 40%; среди тикетов, где правила нужны, 13 из 30 |
| Казахский и узбекский (15%) | язык ответа совпадает с языком игрока | 78,8% (LLM, 40) / 82,3% (шаблоны, 1000) |
| | оценка судьи: uz / kk (черновик против админа) | 1,75 против 3,5 (n=4) / 1,5 против 1,5 (n=2) |
| | проверка носителем | казахские шаблоны проверены (Рахат); узбекские не проверялись |
| Стоимость и латентность (10%) | цена на тикет | $0 факт (бесплатный тариф); ≈ **$0,00032** расчётная |
| | задержка вызова LLM p50 / p95 (одиночный тикет) | **0,98** / 4,97 с |
| | задержка тикета p50 / p95 в прогоне с LLM | 5,0 / 5,27 с: очередь бесплатного лимита, см. ниже |
| | задержка тикета p50 / p95 без LLM (1000) | 0,16 / 0,30 с |
| Человек в контуре | доля `needs_human` | 48,3% (шаблоны, 1000); 100% (LLM, 40) |
| Контракт и правила | ошибок / нарушений контракта / обещаний / пропусков `needs_human_always` | 0 / 0 / 0 / 0 |

Как читать цифры:

- **Задержка в прогоне с LLM (около 5 с) — это не скорость модели, а очередь бесплатного лимита**:
  генератор ограничен 12 запросами в минуту, то есть ждёт до 5 с между вызовами. Одиночный тикет
  отвечает за 0,98 с (p50, замер генератора). На платном тарифе этой очереди нет.
- **Судья оценил 15 из 40 тикетов**: на бесплатном тарифе закончилась дневная квота. Выборки по
  языкам очень малы (uz 4, kk 2), выводы по ним предварительные. Судья — LLM, а не админы.
- Прогон с LLM на 40 тикетах: 36 из них жалобы, поэтому доля `needs_human` в нём не сравнима с
  прогоном на 1000.

## Стоимость

Стоимость тикета = только генератор черновиков. Фактически **$0** (бесплатный тариф Gemini API).
Расчётная цена по прайсу Google на 31.10.2026 (платный тариф Standard) для `gemini-3.1-flash-lite`:
$0,25 за 1 млн входных и $1,50 за 1 млн выходных токенов (токены размышления оплачиваются как
выходные). При среднем тикете около 740 входных и 90 выходных токенов это ≈ **$0,00032 на тикет**,
примерно в 6 раз ниже лимита кейса $0,002. Судья `gemini-3.5-flash`: бесплатный тариф, в стоимость
сервиса не входит. Подробный расчёт в [evaluation.md](evaluation.md#стоимость).

## Ограничения

- В данных нет категорий и приоритетов: классификацию оцениваем на небольшом золотом наборе
  (120 тикетов), размеченном с помощью LLM и проверенном человеком.
- Судья — LLM, а не админы Grand Mobile; его оценка лишь приближает слепую оценку жюри.
- Качество LLM-черновиков измерено на 40 тикетах, а судья успел оценить 15 из них (дневная квота
  бесплатного тарифа); по kk и uz это единицы тикетов.
- Задержка в прогоне с LLM ограничена очередью бесплатного лимита (12 запросов в минуту), поэтому
  p95 тикета 5,27 с выше цели 5 с; одиночный вызов LLM укладывается в цель.
- Коды части разделов правил не подтверждены данными.
- Настоящих казахских тикетов в valid мало, метка `kk` часто стоит на украинском тексте.
- Бесплатный тариф Gemini: по правилам Google содержимое запросов может использоваться для
  улучшения продуктов; для продакшена нужен платный тариф.

## Как воспроизвести

```
cp .env.example .env     # DATA_DIR, GEMINI_API_KEY, DRAFT_PRICE_IN_PER_M=0.25, DRAFT_PRICE_OUT_PER_M=1.50
make serve               # в отдельном терминале
make eval                # метрики на valid
make eval-gold           # + золотой набор (gold.jsonl в репозитории не хранится)
make eval-latency        # задержка без очереди
python -m evaluation.judge --pred results/<run>/pred.jsonl --n 40
python -m evaluation.cost --pred results/<run>/pred.jsonl
```
