# drafts/ — генерация черновиков ответа игроку

Один вызов LLM со structured output. Задача: ответ, который админ отправит почти без правок, без выдуманных
правил и без лишних обещаний.

## Подключение в /triage
`app/interfaces.py: generate_draft(req, lang, rules)` вызывает `drafts.adapter.generate_draft`.
Список `rules` приходит из `retrieval` и служит whitelist цитат: ссылаться можно только на него.

## Что гарантирует код
- Цитаты только из переданных `rules`: enum в схеме и пост-проверка `cited` и текста.
- Нет обещаний разбана, возврата, наказания другого игрока (проверка по выходу для ru/kk/uz/en).
- При нарушении один повтор, затем безопасный шаблон без цитат.
- Пустые репорты («помогите», «ау») отвечаются шаблоном без LLM.
- Сбой или таймаут LLM: шаблон. Решение о `needs_human` принимают guards в `retrieval`.

## Файлы
| Файл | Назначение |
|---|---|
| `adapter.py` | Адаптер под каркас `/triage` (TriageRequest, Rule -> DraftReply), `warmup()` для индекса примеров |
| `generate.py` | Ядро: промпт, structured output, проверки, шаблонный запасной вариант |
| `examples.py` | Few-shot: ответы админов из train по сходству текста (нужен `DATA_DIR`) |
| `rules.py` | Загрузка `rules.json`, формат цитаты «2.1 ОП», запасной отбор правил |
| `templates.py` | Шаблоны ru/kk/uz/en (kk и uz требуют проверки носителем) |
| `llm.py`, `config.py` | Клиент модели и настройки из окружения |
| `bench.py` | Замер: `python -m drafts.bench 40` (стоимость, задержка, доля fallback) |
| `tests/` | `pytest drafts/tests` |

## Настройка (.env, не в репозитории)
`GEMINI_API_KEY`, `DATA_DIR` (папка с `rules.json`, `taxonomy.json`, `tickets_*`), необязательно `DRAFT_MODEL`
(по умолчанию `gemini-3.1-flash-lite`), `DRAFT_PRICE_IN_PER_M` и `DRAFT_PRICE_OUT_PER_M` ($ за 1 млн токенов, пусто = 0),
`DRAFT_THINKING_BUDGET` (по умолчанию 0), `DRAFT_TIMEOUT` (с на вызов, по умолчанию 5), `DRAFT_EXAMPLES=0` чтобы отключить примеры.

## Цели и бюджет
Не дороже $0.002 за тикет и p95 до 5 секунд. Контекст ограничен: до 4 правил, 2 примера, текст игрока до 500 символов.

## Открытые вопросы
- Стоимость и задержка пока расчётные, нужен прогон `bench.py` с ключом.
- Коды разделов кроме ОП, ЖБ, GZ (ЛД, ПГО, ГВ, СМ, FW, ФВ) в `rules.py` подобраны по данным.
- Шаблоны kk и uz написаны вручную.
