# evaluation/ — оценка, kk/uz, стоимость (ветка alikhan-eval)

Харнесс на стандартной библиотеке (для судьи нужен `google-genai`). Данные из `DATA_DIR`, в репозиторий не копируются.
Тексты тикетов есть только в `results/` и CSV (оба в .gitignore); `summary.json` содержит одни агрегаты.

| Файл | Что делает |
|---|---|
| `run_eval.py` | Прогон valid через `POST /triage`: распределения, needs_human, цитаты, контракт, правила кейса, язык, задержка; `--gold` даёт accuracy и macro-F1. Сообщения админа в сервис не уходят |
| `citations.py` | Каждая цитата существует в rules.json и релевантна (taxonomy / ответ админа); доля выдуманных должна быть 0 |
| `promises.py` | Обещания разбана, возврата, наказания (ru/kk/uz/en); при обещании needs_human обязан быть true |
| `judge.py` | LLM-судья на Gemini Flash (другая модель, чем генератор на Flash-Lite), слепое сравнение с ответом админа, 1-5. `GEMINI_API_KEY`, `JUDGE_MODEL`, `JUDGE_RPM` (по умолчанию 5), `JUDGE_PRICE_IN_PER_M` / `JUDGE_PRICE_OUT_PER_M`. «Размышление» Flash выключено (`JUDGE_THINKING_BUDGET=0`). Пауза и повтор при 429 / RESOURCE_EXHAUSTED, остановка при исчерпании дневной квоты, докачка: уже оценённые тикеты пропускаются. Выборка 30-50 |
| `multilang.py` | cp1251-двойники до/после normalize_text, алфавит и язык черновиков kk/uz, CSV для носителей |
| `cost.py` | Фактическая цена (`X-Cost-Usd`, на бесплатном Gemini 0) и расчётная по платному прайсу (токены × `DRAFT_PRICE_IN_PER_M` / `DRAFT_PRICE_OUT_PER_M`, цена генератора; судья в стоимость сервиса не входит); p50/p95/p99, доля сверх лимита, разрезы по языку и kind |
| `compare.py` | Сравнение двух прогонов: метрики, смена категорий, новые цитаты |
| `make_gold.py` | Выборка и конвертация ручной разметки (золотой набор) |
| `stub_server.py` | Заглушка `/triage` для отладки харнесса |

Сервис должен отдавать заголовки `X-Cost-Usd` (или `X-Tokens-In` / `X-Tokens-Out`), иначе `cost.py` не увидит стоимость.
Запуск: `make eval-stub`, `make eval`, `make eval-latency`, `make eval-cost`, `make eval-test`.
Метрики классификации без `--gold` считаются только как распределения: в данных нет настоящих категорий.

Цитаты с кодами раздела, не подтверждёнными данными (подтверждены ОП, ЖБ, GZ, ПГО), не считаются выдуманными, а идут в счётчик `unconfirmed_code_cites`: у Тамера и Рахата таблицы кодов расходятся.
